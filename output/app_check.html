Known limitations

NOTE

Things this test run could not cover, stated plainly

  • No product is sold out in every size. 145 of 612 size rows are zero, but every product has stock somewhere, so the fully sold-out path and the sold_out badge are written but could not be exercised with real data.
  • The products-page search box does not use the B1 normalization. That improvement lives in the backend; the grid filters client-side against the bundled snapshot. Typing “grey” in the chat finds 50 products; typing it in the grid search still finds 0.
  • The rate limiter holds state in process memory. Correct for one worker, wrong for a multi-process deployment where each worker would keep its own counter.
  • Sessions never expire and the token is kept in localStorage rather than an HttpOnly cookie. Both are noted in the harness document.
  • The 45-second agent timeout was not triggered naturally — observed turns ran 2–20 seconds. The handler is in place and the error path was reviewed, but no real timeout occurred during this run.
